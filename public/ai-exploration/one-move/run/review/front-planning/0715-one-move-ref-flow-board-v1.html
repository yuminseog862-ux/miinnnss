8.1 권장 3층 압축 모델

층포함 내용압축 정도비고
L0 해시 포인터 정본 경로 + 역할 + (가능 시) SHA-256 최대 압축 · 바이트 최소 항상 포함. 원문 대체 금지.
L1 결정 요약 H1 promise/pillars/do-not-serve · 3테이블 축 한 표 · S00–S08 one-liner · Overlay A/B · 하이라이트 위계 · Full World 5단계 · 86 ops 표 중간 압축 (1–3페이지 분량 산문/표) 00 작성 시 “무엇을 잠글지” 즉시 읽기용. 연출 문장 미학은 L2.
L2 표현 정본 direction-composition-lock-v1.md 전문 · section-storyline… 전문 · target 전문 무압축 / 원문 유지 pack이 인라인으로 넣지 말고 필수 오픈 파일로 지정. 00 promote 시 storyline lock verbatim.
L3 픽셀 레프 멤버별 대표 셀 3–8장 + 86 스파인 5셀 (단일 프레임 우선) 선택 첨부 · 시트 전체 금지 contact sheet 통째 첨부 금지. 01R 전엔 “후보 포인터”만.

8.2 00 context pack에 대한 명시 제안 (Founder 선택지)

옵션 P — Pointer-first (권장 기본)

  • Pack JSON/텍스트: L0+L1 only
  • L2는 “must-read paths” 목록 + hash
  • 이미지 0장 또는 멤버당 1 thumb
  • 00 작성 세션이 L2 파일을 직접 연다

표현 손실 최소 · 토큰 절약

옵션 E — Expression-inline

  • L1 + direction body 핵심 섹션 인라인
  • section-storyline S00–S08 전문 인라인
  • 레프는 포인터만

pack 비대 · 표현 보존 강함

옵션 V — Visual-heavy

  • L1 + L3 대표 셀 다수 첨부
  • L2는 포인터
  • 00보다 01R 직전 세션에 적합

00에는 비권장

제안 락 (검수 후 확인 바람): 00 진입 context pack = 옵션 P (Pointer-first). 즉 pack 자체는 L0+L1만 싣고, Founder 연출 문장(L2)은 압축하지 않은 채 정본 파일을 필독으로 유지한다. “pack에 다 넣느라 표현을 요약”하는 경로는 금지.
