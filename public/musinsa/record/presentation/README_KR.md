# 포트폴리오 웹 정리본

## 기준 파일

- `musinsa-mujinjang-case-study.html`
  - 현재 기준 파일
  - 포트폴리오 저장소로 옮기기 전, 이 폴더 안에서 검토하기 위한 정적 웹 포트폴리오
  - 마스터 포트폴리오의 덱형 레이아웃 문법을 참고해 9개 슬라이드로 재구성
  - 최종 30초 제출 영상 재생 영역 포함
  - 화면 표시 문구는 한국어 기준

## 슬라이드 구성

1. 커버: 프로젝트명, 한 줄 포지셔닝, 대표 캐릭터 3장
2. 최종 결과: 최종 영상 재생과 핵심 결과 정리
3. 기획 스파인: 축원굿 아이디어와 다양성 구조
4. 역할: 나의 기여와 팀 협업을 분리한 크레딧
5. 최종 흐름: 실제 제출본 기준 시간대별 비트와 최종 컨택트시트
6. 캐릭터 시스템: 최종 사용 인물, 압축 사용, 후보 제외 자산 구분
7. 제작 과정: 스토리보드와 생성 검토 대표 보드 3개
8. 버전 변화: 초안에서 최종본으로 바뀐 판단
9. 산출물 정리: 제출본과 제작 아카이브를 구분한 증거 자료 정리
