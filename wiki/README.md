# Portfolio Wiki

이 wiki는 포트폴리오 내부 자료를 다시 찾고 고치기 쉽게 만드는 관리 레이어다. 원본 이미지, 영상, 구현 코드, 작업 문서는 각자의 위치에 두고, 이곳에서는 어떤 자료가 어떤 프로젝트에 속하는지와 어떤 표현 규칙으로 포트폴리오에 쓰이는지를 정리한다.

## 운영 원칙

- 원본 파일은 `public/**`, `docs/**`, `src/**`에 둔다. `wiki/**`에는 원본을 복사하지 않는다.
- `wiki/**`는 현재 상태를 읽기 쉽게 만든 색인이다. 실제 코드나 파일과 충돌하면 실제 코드와 원본 파일을 기준으로 보고 wiki를 갱신한다.
- 공개 페이지에서 쓰는 런타임 에셋은 `public/**` 경로가 기준이다.
- 내부 정리 자료와 원본 리서치는 `docs/**` 경로가 기준이다.
- 페이지 문구와 케이스 데이터는 `src/data/**`, 슬라이드형 덱 데이터는 `src/lib/portfolio-deck/**`를 기준으로 본다.
- 이미지나 영상 파일을 실제로 이동할 때는 참조 경로를 먼저 찾고, 이동 후 빌드와 화면 확인까지 같이 한다.

## 문서 구조

- `INDEX.md`: wiki 전체 색인.
- `SOURCE_MAP.md`: 원본 자료 위치와 책임 범위.
- `media/*.md`: 프로젝트별 이미지, 영상, 증거 자료 인벤토리.
- `topics/*.md`: 반복 표현, 레이아웃 판단, 케이스 작성 규칙.

## 업데이트 규칙

새 프로젝트나 자료가 들어오면 다음 순서로 정리한다.

1. 원본 위치를 먼저 확정한다.
2. `wiki/media/`의 해당 프로젝트 문서에 자료 역할과 경로를 추가한다.
3. 공개 페이지나 슬라이드에 쓰이면 `src/data/**` 또는 `src/lib/portfolio-deck/**`의 참조 위치를 함께 남긴다.
4. 표현 방식이 반복될 만큼 쓸모 있으면 `wiki/topics/portfolio-expression-map.md`에 추가한다.
