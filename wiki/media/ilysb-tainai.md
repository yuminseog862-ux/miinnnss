# ILYSB / TainAI Media

## 프로젝트 역할

ILYSB와 TainAI 관련 자료는 아이디어를 MVP 화면으로 바꾸고, 직접 반응을 본 뒤 중단 또는 보류 판단을 남긴 케이스로 묶는다.

## 현재 공개 에셋

### ILYSB flow

- `public/work/ilysb-flow/`
- `public/ilysb/flow/`

`public/work/ilysb-flow/` 안의 이미지 파일명은 모두 `ilysb-` prefix를 붙였다.
`public/ilysb/flow/`는 docs에 남아 있던 ILYSB flow 이미지를 WebP로 최적화해 프로젝트 전용 public 위치로 옮긴 것이다.

### TainAI prototype

TainAI는 회사/지원 포트폴리오 축으로 보고, prototype 원본은 `docs/projects/tainai/prototypes/`에 유지한다. 프로젝트별 public 이동 대상에는 넣지 않는다.

## 표현 기준

- 핵심 문장: 추상적인 아이디어를 기능과 화면으로 빠르게 바꾸고, 직접 반응을 본 뒤 다음 결정을 내렸다.
- 반복 구조: 문제 정의 -> MVP 구현 -> 공개 테스트 -> 결정.
- 강조점: 작은 테스트, 반응 기반 판단, 중단/보류를 숨기지 않는 정리.
- 피해야 할 표현: 중단한 프로젝트를 성공 사례처럼 포장하지 않는다.

## 이동 메모

기존 docs/ilysb/, docs/Still unsaid/, docs/tainai/ilysb_evidence.md, docs/tainai/tainai*, docs/tainai/man-* 자료는 `docs/projects/ilysb/`와 `docs/projects/tainai/`로 이동했다.
