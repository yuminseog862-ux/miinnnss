# Creative / BlueGarage Media

## 프로젝트 역할

Creative / BlueGarage는 아직 독립 프로젝트로 확정하지 않은 creative appendix, BlueGarage 제출 패키지, 전체 목업을 관리한다. AHEYA, AB-Luna, SFTI, ADSB처럼 소유 프로젝트가 분명한 자료는 각 프로젝트 문서로 보냈다.

## 현재 공개 에셋

BlueGarage appendix의 AHEYA 관련 공개 자산은 `public/aheya/page-assets/`와 `public/aheya/worldbuilding/`으로 이동했다. ADSB, SFTI, OpenClaw 자료는 각각 `public/adsb/`, `public/sfti/`, `public/aheya/openclaw/`로 이동했다.

## 내부 원본과 작업 문서

- `docs/projects/bluegarage/application-core/`
- `docs/projects/bluegarage/bluegarage_final.md`
- `docs/projects/bluegarage/section-mockups-png/`

## 표현 기준

- 핵심 문장: 정체성과 감정을 캐릭터, 상징, 비주얼 콘셉트로 번역한다.
- 강조점: 관계성, 첫인상, 공개 채널에서 읽히는 장면, 레퍼런스와 변주.
- 피해야 할 표현: 단순 이미지 나열로 보이지 않게, 각 이미지가 어떤 판단을 보여주는지 붙인다.

## 이동 메모

기존 docs/bluegarage/appendix/의 프로젝트별 자료는 AHEYA, ADSB, SFTI로 분리했다. AHEYA character, zodiac, greek, egypt, glass, sakura 자료는 public AHEYA worldbuilding 아래로 옮겼고, docs appendix residue는 제거했다.
