# 채용 플랫폼 지원 정본

작성일: 2026-06-18  
상태: 잡코리아/원티드 입력용 통합 정본. 제출 문안은 이 파일만 수정한다.  
Chrome 확인: 잡코리아 `이력서 작성`, 원티드 `이력서 편집` 화면의 입력칸 구조 반영.  
보조 파일: `job-platform-self-introduction.md`, `job-platform-resume.md`는 안내사항/고려사항 메모로만 사용한다.

## 정본 운영 원칙

- 채용 플랫폼 입력 문안은 이 파일 하나에서만 관리한다.
- 기존 분할 파일 두 개에는 정본 문안을 복사하지 않고, 작성 기준과 플랫폼별 고려사항만 남긴다.
- 회사별로 바꾸는 부분은 `[회사명]`, 회사 관심 문장, 공고 업무 연결 문장, 입사 후 기여 문장으로 제한한다.
- 자소서 본문 메인 사례는 `MUSINSA`, `ADSB`, `Loom` 세 개만 사용한다.
- 이력서/프로젝트 칸에는 `AHEYA`, `SFTI-CMU`를 보조 사례로 추가할 수 있다.
- `LOW`는 사용하지 않는다.
- `공개 가능한`, `proof surface`, `경험을 쌓았습니다` 같은 방어적이거나 약한 표현은 쓰지 않는다.
- `브랜드 메시지`는 MUSINSA/ADSB처럼 브랜드 맥락이 분명한 곳에만 쓰고, 상위 포지셔닝은 `기획 의도와 메시지`로 쓴다.
- 검증되지 않은 수상, 매출, 전환율, 팬 반응, 공식 협업 성과는 쓰지 않는다.

## 플랫폼별 입력 순서

### 잡코리아

Chrome 화면에서 확인한 섹션 순서:

1. 인적사항: 직접 입력/확인
2. 희망직무: `AI기획자`, `AI사업전략`, `AI콘텐츠크리에이터` 중심으로 유지하고 공고에 맞게 조정
3. 스킬: 아래 `스킬 태그`의 잡코리아 항목 사용
4. 학력: 직접 입력/확인
5. 경력: 실제 회사 경력이 아니면 개인 프로젝트를 억지로 넣지 않는다
6. 인턴·대외활동: `ADSB 산학협력` 우선, 필요 시 `SFTI-CMU` 보조
7. 어학: 직접 입력/확인
8. 포트폴리오: 통합 허브 + 대표 프로젝트 링크 제출
9. 취업우대·병역: 직접 입력/확인
10. 자기소개서: 아래 `잡코리아 자기소개서 최종본` 사용
11. 희망근무조건: 공고/희망 조건에 맞게 직접 입력

잡코리아 화면에는 별도 `프로젝트 경험` 칸이 보이지 않으므로, `MUSINSA`와 `Loom`은 자기소개서와 포트폴리오 링크로 보여준다. 활동 칸에는 성격이 맞는 `ADSB 산학협력`만 우선 입력한다.

### 원티드

Chrome 화면에서 확인한 입력 흐름:

1. 이력서 제목: `AI Creative Portfolio` 또는 공고 맞춤 제목
2. 기본 정보: 이름, 연락처, 이메일 직접 확인
3. 간단소개: 아래 `원티드 간단소개` 사용. 화면 안내 기준 5줄 이내로 유지
4. 프로젝트/경험: `MUSINSA`, `Loom`, `ADSB`, 필요 시 `AHEYA`, `SFTI-CMU`
5. 학력: 학교/전공 및 이수 과목 직접 확인
6. 활동: ADSB/SFTI-CMU처럼 활동 칸에 맞는 항목만 사용
7. 스킬: 실제 자동완성에 뜨는 태그만 선택
8. 어학/시험: 필요 항목 직접 입력
9. 링크: 통합 포트폴리오를 1번으로 넣고, 여유가 있으면 Loom/MUSINSA/ADSB 링크 추가

## 잡코리아 자기소개서 최종본

AI로 숏폼 광고·패션 영상·AI 아이돌 음악·영상 콘텐츠를 기획하고 제작한 경험

저는 AI를 활용해 기획 의도와 메시지를 숏폼 광고, 패션 영상, AI 아이돌 음악·영상 콘텐츠, 웹 경험으로 구체화해 왔습니다. 작업을 시작할 때는 먼저 타깃이 어디에서 멈추고 무엇을 기억해야 하는지 기준을 잡고, 그 기준에 맞춰 메시지 구조와 스토리보드, 장면 흐름을 설계한 뒤 레퍼런스와 AI 도구로 장면 후보를 만들고 실제 콘텐츠로 옮깁니다. 단순히 보기 좋은 장면보다, 전달하려는 메시지가 장면 흐름 안에서 분명하게 남는지를 중요하게 봅니다.

[주요 경험 및 직무 역량]

무신사 AI 광고제에서는 3인 팀으로 30초 AI 숏폼 광고 제출본을 제작하며 '편견을 벗다, 다양성을 입다, 무진장을 만나다'라는 메시지를 영상화 초안과 주요 스토리보드로 구체화했습니다. 메시지가 장면마다 흩어지지 않도록 인물, 스타일, 장면 흐름을 맞추며 광고의 전체 방향을 잡았습니다. 팀 작업에서는 많은 아이디어를 모으는 것보다, 모두가 같은 메시지 기준을 보고 결과물을 하나의 흐름으로 맞추는 데 집중했습니다.

ADSB 산학협력에서는 Andersson Bell 브랜드를 대상으로 약 3개월간 3인 팀으로 진행한 생성형 AI 기반 패션 영상 프로젝트에 참여했습니다. 팀 내에서는 초기 기획 방향과 브랜드 리서치를 바탕으로 숏폼에 필요한 장면 흐름과 컷 구성을 구체화했고, 스토리보드 기준에 맞춰 컷 이미지와 개별 AI 영상 클립을 제작했습니다. 이후 Adobe Premiere Pro에서 클립 순서와 흐름을 연결 편집하고, 실무진 피드백 반영 후 약 15초 AI 숏폼 영상으로 완성했습니다.

Loom 개인 프로젝트에서는 13명 AI 아이돌 IP를 음악, 영상, 숏폼 클립, 웹페이지가 연결된 콘텐츠로 구성했습니다. Root Signal과 Pulso를 중심으로 곡 방향, 멤버별 정체성, 스토리보드, 영상 흐름을 정리했고, 실제 제작 범위는 음악, 뮤직비디오형 영상, TikTok/X용 클립, 멤버 아카이브 중심으로 만들었습니다. Harne 투표는 팬 참여 흐름을 보여주는 기획 요소로 두었고, Pulso는 뮤직비디오형 코어 영상에서 멤버/댄스 장면을 컷다운해 숏폼으로 확장하는 예시로 설계했습니다.

[AI 활용 방식]

제 강점은 아이디어를 많이 나열하는 것보다, 전달할 의도와 장면 기준을 먼저 세우고 결과물이 한 흐름으로 보이게 정리하는 데 있습니다. 생성형 AI는 각 흐름에서 최대한 자동화에 가깝게, 최소한의 개입으로 반복할 수 있도록 역할을 나눠 사용했습니다. 먼저 LLM으로 무엇을 만들지 기획하고, 캐릭터의 감정, 장면 의도, 컷 흐름을 구체화했습니다. 이후 구체화된 기획을 coding agent에 넘겨 이미지 생성용 프롬프트로 정리했고, API를 활용해 여러 이미지 후보를 일괄 생성했습니다. 생성된 이미지는 컨택트 시트처럼 모아 의도한 인상과 장면 흐름에 가까운지 검토했고, 필요한 경우 수정 방향을 정리해 이미지 후보를 다시 조정했습니다. 이미지 방향이 잡힌 뒤에는 coding agent로 영상화 프롬프트를 다시 뽑고, Grok Imagine으로 단편 영상이나 완성형 컷 후보를 제작했습니다. 마지막으로 생성된 클립을 모아 CapCut과 coding agent를 활용해 컷 정리와 편집 확인을 진행했습니다.

[입사 후 기여]

입사 후에는 [회사명]의 기획 의도와 메시지를 숏폼 기획안, 장면 구성, 이미지·영상 콘텐츠, 게시용 문장으로 빠르게 전환해 실행 가능한 콘텐츠 제작에 기여하겠습니다. 무신사와 ADSB 프로젝트에서 경험한 메시지 중심 제작 방식과 Loom에서 활용한 AI 제작 흐름을 바탕으로, 반복 작업은 효율화하고 핵심 메시지와 완성도 판단에는 더 집중하겠습니다.

- 공식 협업, 수상, 매출 개선처럼 검증되지 않은 성과 표현
- "AI를 잘 다룬다"처럼 막연한 표현
- PM/개발자로 과하게 포지셔닝하는 표현
- `공개 가능한`, `proof surface`, `운영 성과`, `팬 반응`, `전환율`
- archive 라우트를 메인 포트폴리오처럼 제출하는 방식

## 변경 기록

### 2026-06-18

- 잡코리아/원티드 입력용 정본을 이 파일 하나로 통합 관리하기로 확정했다.
- Loom은 `LOW`를 제외하고, Root Signal/Pulso 중심의 음악, 뮤직비디오형 영상, 숏폼 컷다운, 멤버 아카이브, 웹/SNS 연결 흐름으로 정리했다.
- Pulso는 긴 코어 영상에서 멤버/댄스 장면을 컷다운해 TikTok/X용 숏폼으로 확장하는 작업 예시로 사용한다.
- Loom 섹션은 역할, 제작 흐름, 산출물 기준으로 설명하고, YouTube/TikTok/X 이동 링크를 포트폴리오 동선으로 둔다.
- 자기소개서는 경력 중심으로 `MUSINSA`, `ADSB`, `Loom`을 메인 사례로 사용하고, `AHEYA`, `SFTI-CMU`는 보조 사례로만 사용한다.
- ADSB는 3인 팀 산학공동연구에서 브랜드 리서치, 컷 구성, 개별 AI 영상 클립 제작, Premiere Pro 연결 편집, 피드백 반영 후 15초 숏폼 완성 흐름으로 정리했다.
- ADSB 설명에서는 톤보정, 편집 후 후보정처럼 직접 수행하지 않은 작업은 쓰지 않는다.
- SFTI-CMU는 수상, 논문 게재, 학술 성과가 아니라 영문 리서치 구조화와 포스터형 제출 자료 정리 경험으로만 사용한다.
- 잡코리아 화면 최종 확인 기준으로 ADSB는 메인 활동 사례로 적합하고, SFTI-CMU는 보조 활동 사례로 유지한다.
